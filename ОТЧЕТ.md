# Краткий отчёт по работе с Git и GitHub

**Тема сайта:** «Строительная бригада».

**Цель работы:** подготовить сайт из нескольких связанных страниц, сохранить этапы разработки с помощью Git и GitHub, а затем опубликовать проект через GitHub Pages.

## Выполненные изменения

1. Подготовлена главная страница `index.html` с услугами, строительными материалами, формой заявки, контактами и административной панелью.
2. Стили и JavaScript вынесены в отдельные файлы `style.css` и `script.js`.
3. В ветке `feature/second-page` добавлена страница `about.html` с информацией о команде и этапах работы, настроены переходы между страницами.
4. В ветке `feature/responsive` добавлены дополнительные медиазапросы для планшетов и небольших телефонов, улучшены состояния фокуса интерактивных элементов.
5. Подготовлен `README.md` с описанием проекта и инструкцией запуска.

## Использованные команды Git

`git init -b main`, `git status`, `git add .`, `git commit`, `git log --oneline`, `git remote add origin`, `git push`, `git switch`, `git branch`, `git pull`, `git diff`.

## Проверка

Необходимо проверить открытие обеих страниц, переходы между ними, загрузку CSS и JavaScript, работу формы и отображение сайта на широком экране, планшете и телефоне. После загрузки проекта на GitHub следует проверить оба Pull Request и публикацию GitHub Pages.

## Результат GitHub

- Репозиторий: добавить ссылку после создания.
- Pull Request №1: добавить ссылку после объединения.
- Pull Request №2: добавить ссылку после объединения.
- GitHub Pages: добавить опубликованную ссылку после включения Pages.

*Примечание: GitHub-репозиторий, Pull Request и публикация не создаются автоматически этим архивом. Их нужно выполнить в своём аккаунте GitHub.*

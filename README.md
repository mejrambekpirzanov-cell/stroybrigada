# Строительная бригада

Учебный веб-сайт строительной бригады. На сайте представлены услуги, строительные материалы, преимущества команды, форма заявки и контактная информация.

## Страницы и возможности

- `index.html` — главная страница с услугами, материалами, формой заявки, контактами и административной панелью.
- `about.html` — информация о команде и этапах работы.
- `style.css` — общие стили и адаптивная вёрстка.
- `script.js` — обработка заявок и функций административной панели.

## Технологии

HTML5, CSS3, JavaScript, Git и GitHub.

## Локальный запуск

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.
3. Для перехода на вторую страницу нажмите «О компании».

## Изменения в ветках

- `feature/second-page` — добавлена страница `about.html` и переходы между страницами.
- `feature/responsive` — улучшена адаптация для планшетов и небольших телефонов, добавлены состояния клавиатурного фокуса.
